# 🚀 Quick Start - Snake Game

## ⚡ Iniciar o Jogo em 3 Passos

### Opção 1: Mais Rápida (JAR)
```bash
java -jar SnakeGame.jar
```

### Opção 2: Script
**Linux/macOS:**
```bash
chmod +x run_snake.sh
./run_snake.sh
```

**Windows:**
```cmd
run_snake.bat
```

### Opção 3: Compilar do Zero
```bash
javac -d bin src/com/snakegame/*.java
java -cp bin com.snakegame.SnakeGame
```

## 🎮 Controles Básicos
